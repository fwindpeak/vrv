操作指南与格式说明

普通 2D 浏览器控制

  • 鼠标左键拖拽：360° / VR180 模式下旋转视角；2D 模式下平移画面
  • 鼠标滚轮 / + - 键：缩放视场角 (FOV)
  • W A S D / 方向键：平滑移动视角方向或平移画面
  • 空格键：播放 / 暂停视频
  • ← / →（视频聚焦或 J / L）：快退 / 快进 5 秒（J/L）
  • R 键：重置视角与缩放
  • F 键：全屏切换 · H 键：隐藏/显示控制栏

双目立体与 Quest VR 模式

  • 在普通 2D 显示器上观看 VR180 SBS / TB 或 360° 立体 时，默认提取左眼单目视角正常渲染，不会出现重影分屏。
  • 在 Meta Quest 等支持 WebXR 的浏览器中点击右上角「进入 VR 模式」，将自动启用左右眼独立立体渲染（头部 3DoF/6DoF 追踪，扳机键可控制视频播放/暂停）。
